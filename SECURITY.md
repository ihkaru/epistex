# Security Policy

## Supported Versions

Only the latest release of the active series receives security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Gnosidex, please follow responsible disclosure guidelines:

- **Do NOT open a public GitHub issue.** Public issues expose users before a patch can be released.
- Use **GitHub Private Vulnerability Reporting** via the "Security" tab of this repository:
  `https://github.com/ihkaru/gnosidex/security/advisories/new`
- Alternatively, report directly to the repository maintainer.

All security vulnerabilities will be promptly addressed, patched, and tagged with an advisory.
